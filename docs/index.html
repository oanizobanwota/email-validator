@ Email Validator

Check that an email address is real before you send to it.

A desktop app for Windows and macOS. Paste one address or a whole list, and find out which ones are well-formed, which mailboxes actually exist, and which are throw-away or catch-all.

⬇ Download for Windows · 64-bit installer · v1.0.0

Also: Windows portable (no install) · macOS Apple Silicon · macOS Intel

Syntax & typos

Rejects malformed addresses and suggests fixes for misspelt providers like gmial.com.

Mail servers

Looks up the domain's MX records, so a domain that cannot receive mail is caught before you send.

Mailbox exists

Asks the domain's mail server whether the exact mailbox is accepted. No email is ever sent.

Lists & export

Paste or import a CSV, validate in parallel, filter the results and export them back to CSV.

Installing on Windows

  1. Run the downloaded Email-Validator-Setup-…exe.
  2. If Windows shows "Windows protected your PC", click More info → Run anyway. The installer is not yet code-signed, which is all that warning means.
  3. Choose a folder and finish. A Desktop and Start-menu shortcut are created.

Installing on macOS

  1. Open the .dmg and drag Email Validator to Applications.
  2. First launch: right-click the app → Open → Open (unsigned app).
Networks that block port 25. Mailbox existence is checked over SMTP. Some home and office networks block outbound port 25; the app shows this in its header, and those checks then come back as "unknown" while syntax and mail-server checks still work.
